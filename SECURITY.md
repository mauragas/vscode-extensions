# Security Policy

This repository contains VS Code extensions, including [Git Branches Panel](https://marketplace.visualstudio.com/items?itemName=karolis-mauragas.git-branches-panel).

## Supported Versions

Only the latest version of each extension published on the Visual Studio Marketplace is supported. Please update before reporting an issue.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](https://github.com/mauragas/vscode-extensions/security/advisories/new). Include what the issue is, how to reproduce it, and which extension/version is affected.

This is a personal, open-source project maintained on a best-effort basis. There is no guaranteed response time or SLA, but reports are taken seriously and fixes are released as new Marketplace versions as soon as reasonably possible.
